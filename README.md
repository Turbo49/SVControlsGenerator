# Manual Pitch

This script aims to provide functionality similar to SV1's Manual Mode.
It allows to obtain a more classic vocaloid sound (either from fast pitch changes or even flat pitch), place control points automatically that can be adjusted afterwards, and control the vibrato manually.

**Features :**

- Transition points, flat pitch lines, and manual vibrato
<img width="598" height="216" alt="image" src="https://github.com/user-attachments/assets/f48c4996-24d0-42d8-b0a2-744e7cf71bda" />

- Parameters panel to tune the pitch to your liking:
  - Flatten pitch: draws a flat line before the vibrato (if it's enabled) to achieve a more robotic sound
  - Start Transition Point: adds a control point near the start of the note: you can change its distance and the pitch offset
  - End Transition Point: similar, but at the end of the note
  - Vibrato: adds multiple control points to create a vibrato effect, with tunable distance, length, frequency and amplitude

# Manual Growl

This script provides 4 different types of effects to add grit to vocals

**Features :**

- Basic growl with adjustable amplitude and note coverage
- Fading variant that can be put at the start or end of a note
- Vocal fry effect at the start or end of a note
- Guttural unvoiced effect
